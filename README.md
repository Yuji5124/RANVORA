# RANVORA（ランヴォラ）

> **誰も知らない世界が、生まれ続ける。**

制作者自身にも予測できない発見が生まれる、自動生成3DアクションRPG。
このリポジトリは **Phase 0（テスト版）** です。真上視点の小さなジオラマ世界で、生き物たちが勝手に暮らし、素材の性質から未知のアイテムが生まれ、放置すると世界が変化していきます。

最重要研究テーマ：**「プレイヤーが何もしなくても、開発者が予測していなかった出来事が生まれるか？」**

---

## ゲーム概要

| エンジン | Phase 0 での実装 |
|---|---|
| **A：自律生態系** | スライム・シカ（草食）・オオカミ（捕食）が空腹・恐怖・視界に基づいて自分で行動。繁殖・分裂・遺伝・変異・移住・絶滅と再移入が起こる |
| **B：未知の合成** | 10種の素材が6つの性質（硬度・重量・熱・水・魔力・弾性）を持ち、2つを合成すると性質の相互作用（蒸気・鍛造・共鳴・燃焼・結晶化・反発・凝縮）で新アイテムが生まれる。固定レシピなし |
| **C：進化する世界** | 植物の成長・拡散・枯死、昼夜サイクル、生き物の移動による分布の変化。すべての出来事は原因IDつきでイベントログに記録 |

## 使用技術

- **Vite 7** + **TypeScript 5.9**
- **Three.js r186**（OrthographicCamera、InstancedMesh、影、カスタムシェーダーで主人公周りの木や屋根を透過）
- **rot.js**（Simplexノイズによる地形生成、A*による道・到達保証・移住経路）
- **Blender 4.4**（ヘッドレス実行のPythonスクリプトでGLBを生成）
- **GLB / glTF**（`public/models/*.glb`）
- **Vitest**（単体テスト）/ **Playwright**（ブラウザ自動テスト）
- **GitHub Pages**（GitHub Actions で自動デプロイ）

## セットアップ

```bash
git clone https://github.com/Yuji5124/RANVORA.git
cd RANVORA
npm install
npm run dev
```

ブラウザで <http://localhost:5173/> を開きます。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー |
| `npm run build` | 型チェック＋本番ビルド（`dist/`） |
| `npm run preview` | ビルド結果の確認 |
| `npm test` | 単体テスト（世界生成・再現性・生態系・合成・図鑑） |
| `npm run test:e2e` | ブラウザ自動テスト（Windows ではインストール済みの Edge を使用） |
| `npm run sim -- <seed> <分>` | 描画なしで世界を早回しし、個体数推移と珍しい出来事を表示 |
| `npm run models` | Blender で全モデルを再生成して `public/models/` に書き出し |

### URL パラメータ

| パラメータ | 例 | 内容 |
|---|---|---|
| `seed` | `?seed=12345` / `?seed=ranvora` | 世界のシード（数字か文字）。省略するとランダムで、URLに書き込まれる |

## 実装済み機能

- **真上視点の3D世界**：OrthographicCamera（約30°傾け、研究パネルで0〜50°に変更可）、主人公追従、主人公の周りの木や屋根をディザで透過して隠れないようにする
- **自動生成フィールド**（72×72タイル）：草地・森・小川（砂地・橋）・道・村（家・井戸・街灯・柵）・宝箱・洞窟入口・岩・鉱脈・花。シードで地形も配置も変わり、BFSで到達できるか確認、届かない場所にはA*で道や橋を通す
- **主人公**：茶髪・赤いマフラー・青い服・革のブーツ・小さな剣・リュック。真上から向きがわかるよう、マフラーの尾・剣・足元の三角マーカーを付けた。待機・歩く・走る・剣攻撃・ダメージ・アイテム取得のアニメーション
- **自律生態系**：各個体は HP・空腹・速度・視界・恐怖・行動状態（散策/待機/食料探し/食事/逃走/休息/狩り/追跡/移住）・個体IDを持つ
  - スライム：ランダム移動、草を食べて大きくなり分裂、危険から逃げる。仲間が多すぎて分裂できないと巨大化する
  - シカ：食料を探す、捕食者を避けて村へ逃げ込む、安全な場所で休む、群れる、繁殖する
  - オオカミ：空腹で狩りを始め、忍び寄ってから全力で追う（スタミナ制）、捕食後は休む、獲物の匂いを追って移住、村には近づきたがらない、飢えるとスライムも食べる
  - 子は親の速度・視界を受け継ぎ、少しずつ変化する。まれに変異体（シロシカ・ゴールドスライム・ギンロウ）が生まれる
- **植物と世界の変化**：植物は成長・拡散・枯死し、昼夜サイクル（240秒）で成長速度が変わる。食料が減ると生き物は移住する。絶滅した種は時間をおいて森の外から再びやってくる
- **素材と未知の合成**：素材10種、合成アイテムを素材に再合成もできる。結果には固有ID（例 `ITM-9CD935`）が付き、同じシード・同じ組み合わせなら同じ結果。武器・魔法・薬・お守り・謎の物体のカテゴリと、火・水・風・雷・土の属性がある
- **図鑑**（localStorage）：生き物・素材・合成アイテム・珍しい出来事を、3Dプレビュー・性質・発見日時つきで記録
- **研究パネル**（`?debug=1`）：FPS、シード、経過時間、tick、個体数とグラフ、種ごとの状態分布・平均の空腹・速度・世代、個体一覧（クリックで追跡、視界を表示）、イベントログ（種類・個体ID・★で絞り込み、原因/対象IDから個体へジャンプ）、一時停止・再開、速度（0.5〜16倍）、世界の再生成、JSON出力、状態の指紋（再現性チェック用）
- **テスト**：単体20件、ブラウザ自動テスト6件

## Blender MCP の利用状況

- **Blender MCP（[ahujasid/blender-mcp](https://github.com/ahujasid/blender-mcp)、現在は mcp-for-blender）は今回は接続できませんでした**。Claude Code の設定は `uvx blender-mcp` で起動する構成ですが、このPCに `uv`/`uvx` がインストールされていないため、起動時に接続が切れました。
- 代わりに **Blender 4.4 本体をヘッドレスで実行** し（`tools/blender/build_models.py`）、指定の順番（主人公 → スライム → 草食動物 → 捕食者 → 木 → 岩 → 家 → 宝箱 → その他）で全18モデルを作り、GLBで書き出しました。箱型パーツには Bevel モディファイアをかけています。
- モデルの形は `src/render/modelSpecs.json` 1つで定義しています。Blenderスクリプトと Three.js のフォールバックが同じ定義を読むので、**原点（足元の中心）・向き（+Z が前）・スケール（1 = 1タイル）・パーツ名** は常に揃います。GLBがない場合は自動でプリミティブ表示になります。
- Blender MCP を使えるようにするには：`uv` をインストールし（`powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`）、Blender にアドオン `addon.py` を入れてサイドバーの「Connect to Claude」を押します。`build_models.py` は MCP の `execute_blender_code` からもそのまま実行できます。

## ディレクトリ構成

```
src/
  core/      乱数（シードごとのストリーム）、イベントログ
  world/     タイル型、世界生成（rot.js）
  sim/       生態系シミュレーション（描画なし・決定的）、種の定義
  items/     素材、合成エンジン、インベントリ
  codex/     図鑑（localStorage）
  render/    モデル（GLB／プリミティブ）、世界・生き物の描画、サムネイル
  game/      ゲームループ、主人公、操作
  ui/        HUD、パネル、ミニマップ、研究パネル
tools/
  blender/   build_models.py（Blender→GLB）、run-blender.mjs
  simulate.ts  描画なしで早回しする研究用スクリプト
tests/unit   Vitest
tests/e2e    Playwright
public/models  Blender が書き出した GLB
```

## 再現性について

- 世界生成・生態系・植物・アイテム出現は、シードから作った独立した乱数ストリームを使います。**プレイヤーが干渉しなければ、同じシードは同じ歴史をたどります**（`npm test` と研究パネルの「指紋」で確認できます）。
- 主人公の行動（攻撃・採取・魔法・接近による恐怖）は世界を変えるので、その後の歴史は分岐します。

## ロードマップ

- **Phase 1**：洞窟内部とダンジョン生成（rot.js の Map 生成も候補）、ボスの試作、セーブ／ロード
- **Phase 2**：村人のAIと村の発展（素材の流通、建物の増築）、季節
- **Phase 3**：合成の深化（素材の性質の遺伝、魔法の連鎖、新素材の発生）、武器・魔法のバリエーション
- **Phase 4**：Blender MCP で本格的なモデル・アニメーションを作り、GLBを差し替える。サウンド、モバイル対応
- **研究**：長時間放置したときの出来事の多様性を測る（イベントの種類・珍しい出来事の頻度・個体数の振れ幅）
